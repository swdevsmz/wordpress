# My Weather Plugin - セットアップガイド

## インストール方法

プラグインは既に以下の場所に配置されています：
```
wordpress_data/app/public/wp-content/plugins/my-weather-plugin/
```

## プラグインの有効化

1. WordPressの管理画面にログインしてください
2. **プラグイン** > **インストール済みプラグイン** に移動
3. **My Weather Plugin** を探して **有効化** をクリック

## 設定方法

1. **設定** > **Weather** に移動
2. 以下の情報を入力してください：
   - **City Name** (都市名): 表示される都市名
   - **Latitude** (緯度): -90 から 90 の範囲
   - **Longitude** (経度): -180 から 180 の範囲
3. **Save Changes** (変更を保存) をクリック

## よくある座標例

| 都市 | 緯度 | 経度 |
|------|------|------|
| 東京 | 35.6762 | 139.6503 |
| ニューヨーク | 40.7128 | -74.0060 |
| ロンドン | 51.5074 | -0.1278 |
| パリ | 48.8566 | 2.3522 |
| シドニー | -33.8688 | 151.2093 |

## ショートコードの使用方法

### フル形式（推奨）
記事やページに以下を挿入してください：
```
[weather]
```

このショートコードは以下を表示します：
- 都市名
- 現在の気温（℃）
- 天気の説明
- 風速（km/h）
- 最終更新時刻

### シンプル形式
テキストのみの簡潔な形式を表示：
```
[weather format="simple"]
```

出力例：
```
Tokyo: 20°C, Partly cloudy
```

## キャッシング

プラグインは以下の目的でキャッシングを使用しています：
- API リクエストの削減
- ウェブサイトのパフォーマンス向上
- Open-Meteo API への負荷軽減

キャッシュ期間: **1時間**

設定を変更するとキャッシュは自動的にクリアされます。

## セキュリティ機能

- ✅ すべてのユーザー入力は検証・サニタイズされます
- ✅ 設定はアドミニストレーターのみが変更可能
- ✅ 出力は XSS 攻撃から保護されます
- ✅ 機密データは保存されません

## API 情報

このプラグインは以下の API を使用します：
- **プロバイダー**: Open-Meteo
- **Web サイト**: https://open-meteo.com
- **API キー**: 不要
- **レート制限**: なし（非商用利用）
- **データソース**: 国の気象サービス

## トラブルシューティング

### 天気情報が表示されない
1. プラグインが有効化されているか確認してください
2. 設定ページで座標が正しく入力されているか確認してください
3. ブラウザのキャッシュをクリアしてください

### 古い天気情報が表示される
- キャッシュは 1 時間保持されます
- 設定ページで座標を再度保存するとキャッシュがクリアされます

### エラーメッセージが表示される
- インターネット接続を確認してください
- Open-Meteo API の状態を https://open-meteo.com で確認してください
